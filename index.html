Am I affected?

One Python file that checks your machine for the Chrome bugs being exploited right now, the old browsers Puppeteer and Playwright leave behind, and the October 2026 PHP, Node.js, BIND, LiteLLM, GitLab and eMudhra issues, and tells you what to do about each one.

No dependencies, and nothing about your machine is sent anywhere. Python 3.8+ on macOS or Linux.

curl -fsSL https://amiaffected.now/run | sh

Rather read it first? run is ten lines; it fetches secinspect.py and advisories.json into a temp folder and runs them. Pass options after sh -s --:

curl -fsSL https://amiaffected.now/run | sh -s -- --html report.html   # HTML report
curl -fsSL https://amiaffected.now/run | sh -s -- --docker             # also scan Docker images
curl -fsSL https://amiaffected.now/run | sh -s -- ~/work               # only search this folder

Exit code is 1 if anything is affected, so it can fail a CI job.

Even the latest Playwright (1.64.1) and Puppeteer (25.16.0) ship builds without the 27 Oct fixes, and Playwright turns Chrome's sandbox off by default. If your agent browses the web, point it at your installed Chrome with channel: 'chrome' and chromiumSandbox: true
