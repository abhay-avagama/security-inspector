PHP (distro packages)

PHP from apt or dnf, judged by the distro's own fixed build: Ubuntu, Debian and RHEL backport fixes without changing the version (Ubuntu 24.04's patched PHP is still 8.3.6). Covers CVE-2026-109618 / 109619 (PHP2Shell, CISA KEV) and the 19 Nov 2026 security releases (17 CVEs, the worst CVE-2026-129289, FPM request smuggling). Builds from deb.sury.org or Remi carry upstream versions and are judged by those: 8.5.13 / 8.4.28 / 8.3.37 / 8.2.36.
