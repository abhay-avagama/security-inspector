PostgreSQL server

Nov 2026 release (12 Nov): 53 CVEs, most of them code execution as the database's OS user by anyone who can create objects (plperl, pltcl, dblink, type confusion, tsvector overflows), plus an unauthenticated restart. Also fixes the Aug 2026 batch. 14.25 is PostgreSQL 14's last release. Public proofs of concept are out for CVE-2026-6460 (13 Nov write-up, crashes 18.6 and leaks memory addresses) and CVE-2026-116331 (16 Nov); no attacks reported.
