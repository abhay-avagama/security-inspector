Puppeteer / Playwright Chromium

Browsers that Puppeteer and Playwright download never update themselves, and Playwright starts Chromium with the sandbox off unless told otherwise. Puppeteer 25.16.0 (Chromium 156.0.8078.47) still ships a build older than 157.0.8103.50; Playwright 1.65.0 ships 158.0.8127.18 but still turns the sandbox off. CVE-2026-87491 and CVE-2026-85046: V8 bugs exploited in the wild (CISA KEV), fixed in 153.0.8010.36; on macOS also CVE-2026-106378, a GPU sandbox escape fixed in 155.0.8059.39; and four critical bugs fixed on 27 Oct 2026 in 156.0.8078.73 (CVE-2026-118306 escapes the sandbox, CVE-2026-118331/118348/118344 run code inside it); and 196 bugs fixed in 157.0.8103.38 (stable on Linux 3 Nov, macOS 5 Nov 2026), 33 of them critical, several running code outside the sandbox (e.g. CVE-2026-121035, CVE-2026-121086, CVE-2026-121189); and CVE-2026-125350, a use-after-free in XML exploited in the wild, fixed on 9 Nov 2026 in 157.0.8103.50.
