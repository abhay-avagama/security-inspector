What it looks for in any skill

For a skill that isn't listed above, the tool checks its files for these patterns. A finding means a person should look, not that the skill is malicious, and a clean result means nothing obvious was found, not that it's safe. All of them are reported as REVIEW.

Hidden instructionWording that tells the agent to override you or keep things from you
Invisible charactersCharacters you can't see but the agent reads: check the file in a hex viewer
Pipes a download into a shellRuns whatever that URL serves at the time, unreviewed
Sends data to a capture serviceA URL used to collect data, rarely needed by a real skill
Hard-coded secretA key or token is written into the skill (value not shown)
Reads credentialsA script touches SSH, cloud or browser credentials
Sets up something that survives a restartA script installs a login item, cron job, service or shell startup line
Hides what it runsA script decodes and runs code it doesn't show
Downloads a program and runs itFetches a program at run time; what runs can change after you reviewed it
Ships a compiled programA binary the agent can run but you can't read
Can run any shell commandAllowed-tools lets the agent run any shell command without asking while this skill is active
Password-protected archiveAn encrypted zip can't be inspected; Snyk saw these in malicious skills
