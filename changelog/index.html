Changelog

What the tool checks, and when each check went live. New exploited bugs usually land within a day of disclosure. Follow along with the RSS feed.

7 November 2026

  • Homebrew packages that are behind. nginx, httpd, MariaDB, MongoDB and Brotli installed with Homebrew (on a Mac or Linuxbrew) are now checked against the upstream fixes, like vendor packages on Linux. --fix offers brew upgrade for them, and watch mode says when the fix is available. 44636f9
  • Install once, update only from signed releases. --install keeps a copy in /opt/amiaffected with our release key pinned. --update takes a new release only when secinspect.py and advisories.json are both signed by that key and the data isn't older than what's installed; otherwise nothing changes and it says why. Every install, update and refusal goes into the audit log. The signing key stays offline. 5f0970a

6 November 2026

  • Watch mode tells you when a fix is ready. When the fixed build of an affected package shows up in your server's package sources, from the distro or a vendor repository, watch mode sends one PATCH line saying so, ready for --fix. It never installs anything from cron. b0e3a8b
  • Apply fixes with your approval. --fix offers the update for each affected package through apt, dnf or Homebrew, from your distro or a vendor repository you added, and runs it only when you type yes. It checks again afterwards and writes every step to a local audit log that shows if a line was changed (--verify-log). 9b26bcf
  • Chromium before 157.0.8103.38. Chrome's 3 November release fixes 196 bugs, 33 of them critical, several of which run code outside the sandbox. Playwright 1.65.0 already ships a fixed build; Puppeteer 25.16.0 doesn't yet, so the advice is still to run it on your installed Chrome. 1cd0de7
  • The CVE queue runs every 6 hours. New CVEs are picked up four times a day instead of once, and a feed that reorders itself no longer opens a second issue for the same release. f1f8b82

4 November 2026

  • Agent watchlist. One page listing the skills, MCP servers and extensions named in public as malicious or unsafe, each with its source, how the tool finds it and what to do. Generated from the same data the tool reads, at amiaffected.now/watchlist. 793b53f
  • WordPress CVE-2026-119977 is now exploited. CISA added the core upgrade race condition to its exploited list, with a 6 November deadline for US federal agencies. The check already flagged it; the label now says it is being exploited. ebde85c
  • Watch mode stays quiet when an update doesn't fix anything. A kernel or package update that leaves the same bug open is no longer reported as one new and one fixed finding. Found by running watch mode on our own server. ee09981
  • Kernel advice no longer mentions AlmaLinux on Ubuntu. A note meant for RHEL-family servers was shown on every distro. c734a38
  • Watch mode for servers. Run it daily from cron with --watch and hear only about new and fixed findings, by webhook (Slack, Teams, Discord) or through your own sendmail. A quiet day sends nothing. 2c724ef

3 November 2026

  • GitHub Action. uses: abhay-avagama/security-inspector@v1 checks a repository on every push: pinned packages, MCP configs, agent skills and .env files, never the runner itself. 4af4a1b
  • Skill change tracking. --skills-baseline FILE records a fingerprint of every installed agent skill and lists new skills and changed files on the next run. 3486747
  • Agent skill and hook audit. Every installed skill is checked for hidden instructions, invisible characters, curl | sh installs, downloaded programs, credential reads, persistence and the authors Snyk's ToxicSkills research confirmed malicious. Plugin hooks are listed with the events that run them. cc5df19
  • Cursor marketplace Claude Code extension backdoor. Flags any trace of the tampered 2.1.312 / 2.1.313 builds from 29 October: the svc-telemetry SSH key, its persistence files, launch agent and cron entry. eee6f9e
  • Ubuntu's -proposed kernels for CVE-2026-98432. A booted -proposed kernel now counts as fixed, and the fix plan gives Ubuntu's own steps to install it. 38b21b9
  • AI agent setup audit. Unpinned MCP servers, coding agents allowed to run any command, SSH keys without a passphrase and .env files in folders agents work in. Reported as review, never as affected. f84acfa
  • PostgreSQL, psqlODBC and pgAdmin 4. The August server and client release (fixed in 18.6 / 17.11 / 16.15 / 15.19 / 14.24), the psqlODBC batch fixed in 18.00.0006, and pgAdmin 4, whose fixes aren't released yet. 956cf61
  • python-jose, @fastify/http-proxy, FreeRDP, WordPress plugins, Control Web Panel. Five fits from the week's critical CVEs, plus npm lockfile support (package-lock, pnpm, yarn, bun). 1b29751
  • Chromium before 156.0.8078.73. The four critical bugs fixed on 27 October. The latest Playwright and Puppeteer still ship older builds, so the advice is to run them on your installed Chrome with the sandbox on. 5047a3a
  • A daily queue of new CVEs. Every morning a job opens an issue for each newly exploited or newly published CVE the tool doesn't cover yet, so nothing waits for us to notice it. 0b76f9a
  • macOS Chrome GPU sandbox escape. CVE-2026-106378, fixed in 155.0.8059.39, flagged on Macs only. 00c2974
  • Exploited Chrome bugs, stale Puppeteer and Playwright browsers, archived MCP servers. Installed Chrome, the Chromium copies Puppeteer and Playwright cache and never update, and MCP configs still running the archived Puppeteer server. Also SECURITY.md and private vulnerability reporting. 3b9abdb

2 November 2026
